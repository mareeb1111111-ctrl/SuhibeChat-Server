# دليل تشغيل خادم SuhibeChat (بيئة Docker الآمنة)

تم إعداد هذه البيئة لتكون آمنة، خفيفة، ومعزولة باستخدام `Docker` و `Docker Compose`. يعتمد الخادم على مستخدم غير جذري (non-root) وصلاحيات مقيدة للحماية من الاختراقات.

## 🚀 التشغيل السريع

تأكد من تعديل ملف `.env` ووضع الـ `SECRET_KEY` وباقي المتغيرات الخاصة بك قبل التشغيل.

1. **بناء الصورة (Image) الخاصة بالتطبيق:**
   ```bash
   docker-compose build
   ```

2. **تشغيل الحاوية (Container) في الخلفية:**
   ```bash
   docker-compose up -d
   ```

3. **عرض سجلات (Logs) التطبيق:**
   ```bash
   docker-compose logs -f
   ```

4. **إيقاف الحاوية (مع الاحتفاظ بالبيانات):**
   ```bash
   docker-compose down
   ```

## 🔒 إعدادات الأمان المطبقة:
- **المستخدم غير الجذري:** يتم تشغيل التطبيق كمستخدم `appuser` لضمان عدم وجود صلاحيات Root داخل الحاوية.
- **نظام الملفات (Read-Only):** الحاوية تعمل بوضعية القراءة فقط `read_only: true`، باستثناء مجلدات البيانات `volumes` المطلوبة (uploads, logs, db) ومجلد `/tmp` (الذي يعمل بـ tmpfs).
- **منع التصعيد (No New Privileges):** يمنع أي ملف داخل الحاوية من زيادة صلاحياته.
- **إسقاط القدرات (Capabilities Drop):** تم إسقاط جميع صلاحيات النواة (Kernel Capabilities) ما عدا الصلاحية الضرورية لفتح منافذ الشبكة (`NET_BIND_SERVICE`).

## 📁 المجلدات الدائمة (Volumes)
- `chat_server.db`: قاعدة البيانات يتم ربطها مباشرة لضمان بقاء البيانات بعد إيقاف الحاوية.
- `uploads/`: لحفظ ملفات المستخدمين.
- `logs/`: لحفظ سجلات التطبيق.

## 🧪 اختبار السيرفر
يمكنك اختبار أن السيرفر يعمل بزيارة الروابط التالية في المتصفح:
- `http://localhost:5000/docs` (واجهة توثيق الـ API).
- `http://localhost:5000/dashboard` (لوحة تحكم المشرف).
